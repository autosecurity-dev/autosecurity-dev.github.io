What it catches

Hijacked packages

Detects when a maintainer account is compromised and a bad version is pushed

Exposed secrets

API keys, tokens, and passwords accidentally committed to your repo

Malicious install scripts

postinstall hooks that run code the moment you install a package

Known bad versions

Blocks packages confirmed malicious by the security community

Auto-fix for malicious packages

Automatically downgrades to the last known-safe version — same major, no breaking changes

Secret rotation guidance

Tells you exactly how to revoke and rotate each leaked credential — Stripe, GitHub, AWS, and more

CVEs in your dependencies

Trivy scans your full dependency tree and flags known vulnerabilities with severity ratings

Code vulnerabilities (SAST)

Semgrep finds SQL injection, XSS, and insecure patterns in your source code

Real example: axios supply chain attack, March 31 2026

A North Korean threat actor hijacked the npm account of axios's lead maintainer and published two backdoored versions downloaded by ~100 million developers. Security Autopilot flags it within seconds of the malicious version appearing — before you ever run npm install.
